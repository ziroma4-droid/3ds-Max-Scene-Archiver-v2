# Max Scene Packager v3.0

Утилита для быстрой архивации сцен 3ds Max со всеми зависимостями (текстурами, прокси, IES и др.) **без запуска 3ds Max**.

![Python](https://img.shields.io/badge/Python-3.7+-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)
![License](https://img.shields.io/badge/License-Attribution%20Required-green.svg)

## 🎯 Возможности

- ✅ Архивация без запуска 3ds Max
- ✅ Парсинг OLE-формата .max файлов
- ✅ Автоматический поиск всех зависимостей
- ✅ Поддержка абсолютных, относительных и сетевых UNC-путей
- ✅ Поиск стандартных текстур и карт в библиотеках Autodesk
- ✅ Поддержка текстур, IES, прокси, кэша, аудио, LUT
- ✅ Организованная структура архива
- ✅ Отчёт о содержимом
- ✅ Предупреждение о пропущенных файлах и ошибках добавления
- ✅ Рекурсивная архивация XRef-сцен и их ресурсов
- ✅ Чтение ресурсов из официального потока Asset Metadata без ложных записей служебных OLE-потоков
- ✅ Автоматическое обновление имени ZIP при каждой смене сцены
- ✅ Пакетная архивация нескольких сцен в отдельные ZIP-файлы
- ✅ Переименование архивов и выбор общей папки назначения
- ✅ Общий прогресс, статусы очереди и остановка после текущей сцены
- ✅ Автоматическое обнаружение установленных версий 3ds Max
- ✅ Пересохранение сцены и `.max`-XRef на три версии назад
- ✅ Простой графический интерфейс

## 🚀 Установка

### 1. Требования

- Python 3.7 или выше
- Windows

### 2. Установка зависимостей

```bash
pip install olefile
```

> ⚠️ `olefile` опционален, но рекомендуется для лучшего парсинга .max файлов

### 3. Запуск

```bash
python "3dsMax Archive.py"
```

## 📖 Использование

### Графический интерфейс

1. **Выберите сцену** — нажмите `...` рядом с полем "Сцена" и выберите .max файл
2. **Укажите архив** — путь заполнится автоматически, или выберите вручную
3. **Выберите типы файлов** — отметьте нужные категории (текстуры, прокси и т.д.)
4. **Нажмите "Создать архив"**

### Пакетная обработка

1. Откройте вкладку **Пакет**
2. Нажмите **Добавить сцены** и выберите несколько `.max`-файлов
3. При необходимости дважды щёлкните имя ZIP в таблице, чтобы переименовать архив
4. Выберите сохранение рядом с каждой сценой или укажите общую папку
5. Нажмите **Архивировать: N**

Сцены обрабатываются последовательно. Ошибка одной сцены не останавливает
остальную очередь. Кнопка **Остановить после текущего** безопасно завершает
текущий ZIP и не начинает следующий.

### Пересохранение для старой версии 3ds Max

1. Включите **Пересохранить для старой версии** в составе архива
2. Выберите установленную версию 3ds Max, которая откроет сцену
3. Выберите один из трёх предыдущих форматов
4. Запустите обычную или пакетную архивацию

Приложение автоматически ищет установленные копии 3ds Max. Для 3ds Max 2024
будут предложены форматы 2023, 2022 и 2021; для 2026 — 2025, 2024 и 2023.
Если установка находится в нестандартной папке, можно вручную указать
`3dsmax.exe`.

Пересохранение выполняется через 3ds Max Batch. Оригинальная сцена не
изменяется: в архив помещается временная копия с именем вида
`scene_Max2021.max`. Существующие `.max`-XRef автоматически пересохраняются в
тот же формат. Операция запускает 3ds Max, поэтому заметно увеличивает
использование CPU, памяти и время создания архива.

### Кнопки

| Кнопка | Описание |
|--------|----------|
| 📦 Создать архив | Создать ZIP-архив сцены |
| Архивировать: N | Создать отдельный ZIP для каждой сцены в очереди |
| Остановить после текущего | Завершить текущий ZIP и остановить пакет |
| 📋 Анализ | Только анализ без архивации |
| 🗑 Очистить | Очистить журнал |

### Настройки

- **Ресурсы сохранить в папку maps/** — все ресурсы помещаются в папку `maps/` внутри архива (иначе сохраняются в корень архива)

## 📁 Структура архива

```
scene_archive.zip
├── scene.max           # Файл сцены
├── maps/
│   ├── texture1.jpg    # Текстуры
│   ├── texture2.png
│   ├── light.ies       # IES файлы
│   ├── proxy.vrmesh    # Прокси
│   ├── color.cube      # LUT файлы
│   ├── texture.jpg     # Первый файл с таким именем
│   └── duplicates_1/
│       └── texture.jpg # Совпавшее имя сохраняется без переименования
├── xrefs/
│   └── linked_scene.max # XRef-сцены
└── _report.txt         # Отчёт об архивации
```

## ⚙️ Как это работает

1. **Парсинг** — скрипт читает .max файл как бинарные данные
2. **Извлечение путей** — находит все пути к внешним файлам (ASCII и UTF-16)
3. **Обход XRef** — рекурсивно анализирует найденные `.max`-сцены с защитой от циклических ссылок
4. **Resolve путей** — относительные пути вычисляются от папки каждой сцены, UNC-пути используются напрямую
5. **Fallback-поиск** — если файл не найден по исходному пути, проверяется папка сцены, затем стандартные библиотеки Autodesk
6. **Проверка** — проверяет существование файлов на диске
7. **Архивация** — добавляет найденные файлы в ZIP-архив

### Технические детали

- Используется библиотека `olefile` для корректного чтения OLE Compound Documents
- Поиск путей в форматах ASCII и UTF-16 LE
- Индексируются стандартные папки Autodesk: `Common Files\Autodesk Shared\Materials`, `3ds Max*\maps`, `3ds Max*\sceneassets`, `3ds Max*\materiallibraries`, а также поставляемые Autodesk bundle-ресурсы из `ProgramData\Autodesk\ApplicationPlugins`
- При совпадении имён оригинальное имя сохраняется: повторные файлы помещаются в `maps/duplicates_1/`, `maps/duplicates_2/` и далее

## ⚠️ Ограничения

- Пути внутри `.max` не изменяются после архивации
- Для пересохранения должна быть установлена подходящая версия 3ds Max
- Возможности новых версий и отсутствующие плагины могут быть несовместимы со старым форматом
- Пересохранение одной сцены ограничено таймаутом 30 минут

## 🐛 Решение проблем

### "olefile не установлен"

```bash
pip install olefile
```

### "Файл не найден"

Убедитесь, что:
- Файл сцены существует
- Пути к ресурсам в сцене актуальны
- Диски с ресурсами подключены

### Не все текстуры найдены

- Проверьте раздел "ОТСУТСТВУЕТ" в отчёте `_report.txt`
- Возможно, файлы были перемещены или удалены
